A crash that starts right after an update is almost always a compatibility or cache problem, and the sequence below resolves nine out of ten cases without engineering.

Steps:
1. Confirm the installed version against the current release notes; if you are one or more versions behind, update first.
2. Clear the application cache (Settings > Advanced > Clear cache) and restart the application, not only the window.
3. If it still crashes, attach the log file from Help > Export diagnostics to this ticket. Tier 2 reads the last 200 lines to find the failing module.

Please include your operating system and version so the engineer can reproduce it.
